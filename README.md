# Longest-distance-of-railway-network
# ファイルの種類
train_ticket_firsterのファイルではビットDPのアルゴリズで実行し、train_ticket.pyのファイルでは深さ優先探索（DFS）+バックトラッキングを用いて実行しています。

テストを行う際に、makeTestInput.pyで指定入力のランダム生成を行い指定回数実行するファイルを作成しております。実行結果からも深さ優先探索（DFS）+バックトラッキングのアルゴリズよりもビットDPのアルゴリズムの方が早いのがわかります。

makeTestInput.pyを実行する際に位置引数(1番目:駅数 2番目:路線数)を指定することで指定した数を生成することができます。
